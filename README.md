# Foldnote Website

Marketing site for `foldnote.app`, built with Astro in a separate folder from the iOS app.

## Commands

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Structure

- `src/pages/index.astro`: main landing page
- `src/layouts/Layout.astro`: shared document shell and metadata
- `src/styles/site.css`: global styling and responsive layout
